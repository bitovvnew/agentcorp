# AgentCorp

**ЖИ-стартаптар симуляторы. LLM-ге компания, ақша мен команда беріп, оның жалдап, босатып, пивот жасап, раунд тартып, (әдетте) ақшасыз қалғанын бақылаңыз.**

Стартапты қай модель жақсы басқарады: GPT, Claude, Gemini әлде Llama? Оларды бір нарыққа шығарып көріңіз.

## Бұл не үшін

Әр компанияның токенмен (◈) шоты, жалақы қоры, шығыны мен жүріс қоры бар. CEO — LLM немесе кіріктірілген стратегия. Бірнеше апта сайын ол неге назар аударатынын, кімді жалдап, кімді босататынын, бағаны, маркетинг шығынын, пивот пен ақша тартуды шешеді. Әлем жауап береді: клиенттер келеді не кетеді, инженерлер мүмкіндік шығарады не мерзімді бұзады, инвесторлар ақша береді не бас тартады. Бұл әрі драма, әрі ұзақ мерзімді шешімдер бенчмаркі: 104 апта, ал ұпай — компания бағасы.

## Жылдам бастау

Кілтсіз: төрт кіріктірілген стратегия демо-лигада ойнайды.

```bash
npx --yes github:bitovvnew/agentcorp#v0.1.2 demo
```

Алғашқы іске қосу браузерде баптауды ашады: жергілікті Ollama-ны табады, кілттерді тексереді және әр компанияға CEO таңдатады.

```bash
npx --yes github:bitovvnew/agentcorp#v0.1.2
```

Windows: `setup.bat` · macOS / Linux: `./setup.sh`

## Тегін, картасыз

Браузердегі «Тегін бастау» түймесі немесе терминалдағы `agentcorp setup --free` тек тегін модельдерді таңдайды: жергілікті Ollama, Groq пен Gemini-дің тегін тарифтері және OpenRouter-дің тегін модельдері (`:free` жұрнағымен). Модель атаулары кодқа жазылмаған: тізім провайдердің API-інен келеді.

```bash
agentcorp setup --free
```

## Ішінде не бар

- Жалақы, жүріс қоры, жалдау мен босату, ынта және бәсекелеске кету
- Тапсырмалар биржасы: CEO ақылы тапсырма жариялайды, қызметкерлер ұсыныс береді
- Шолулар, әр тоқсан сайын директорлар кеңесі, сәтсіздіктен кейін CEO-ны ауыстыру
- Seed-тен Series E-ге дейінгі раундтар, бридждер және үлестің азаюы
- Ортақ нарық: бір сегменттегі компаниялар клиенттерді бөліседі
- Дашборд: лига, бағалау жарысы, P&L, ұйымдық құрылым, компания Slack-і, хроника, нарық соққылары
- Кеңес отырыстарының қайталауы, питч-дек, қазанама немесе табыс тарихы (PNG), маусым бейнесі (WebM)
- Маусым режимі: сидтер мен сценарийлер бойынша бірнеше жарыс, ұпай кестесі
- Қорғаныс: промпттарды оқшаулау, токен лимиттері, rate limit, кілттер журналдарға түспейді

## Командалар

```text
agentcorp                      setup / league
agentcorp setup [--web|--free]
agentcorp models <openai|anthropic|gemini|openrouter|groq|ollama>
agentcorp league --brains <a,b,…> [--scenario ai-winter]
agentcorp season --brains <a,b,…> --runs 5
agentcorp offline
agentcorp replay <file.json>  ·  agentcorp export <file.json>  ·  agentcorp pitch <file.json>
```

## Кілттер және қауіпсіздік

Кілттер тек компьютеріңіздегі `.agentcorp/config.json` файлында сақталады. Бума git-тен тыс, кілттер журналдардан, қателерден және жазбалардан өшіріледі. Дашборд сервері тек 127.0.0.1-де тыңдайды.
