# AgentCorp

**Симулятор ИИ-стартапов. Дайте LLM компанию, деньги и команду и смотрите, как она нанимает, увольняет, пивотит, привлекает раунды и (обычно) остаётся без денег.**

Какая модель лучше всех руководит стартапом: GPT, Claude, Gemini или Llama? Выпустите их на один рынок и узнайте.

## Зачем это

Каждая компания живёт на счёте в токенах (◈), платит зарплаты, сжигает деньги и считает запас хода. CEO — это LLM или встроенная стратегия. Раз в несколько недель он решает, на чём сосредоточиться, кого нанять и уволить, какую цену назначить, сколько тратить на маркетинг, пивотить ли и привлекать ли деньги. Мир отвечает: клиенты приходят и уходят, инженеры выпускают функции или срывают сроки, инвесторы дают деньги или отказывают, а советы директоров созывают экстренные заседания. Это драма и одновременно бенчмарк долгосрочных решений: 104 недели, а счёт — оценка компании.

## Быстрый старт

Без ключей: четыре встроенные стратегии играют демо-лигу.

```bash
npx --yes github:bitovvnew/agentcorp#v0.1.2 demo
```

Первый запуск открывает настройку в браузере: найдёт локальный Ollama, проверит ключи и предложит выбрать CEO для каждой компании.

```bash
npx --yes github:bitovvnew/agentcorp#v0.1.2
```

Windows: `setup.bat` · macOS / Linux: `./setup.sh`

## Бесплатно, без карты

Кнопка «Бесплатный старт» в браузере или `agentcorp setup --free` в терминале выбирают только бесплатные модели: локальный Ollama, бесплатные тарифы Groq и Gemini и бесплатные модели OpenRouter (с суффиксом `:free`). Названия моделей не зашиты в код: список приходит из API провайдера.

```bash
agentcorp setup --free
```

## Что внутри

- Зарплаты, запас хода, найм и увольнения, мотивация и уходы к конкурентам
- Биржа задач: CEO выставляет задачи с оплатой, сотрудники делают ставки
- Ревью, советы директоров каждый квартал, смена CEO после провала
- Раунды от Seed до Series E, бриджи и размытие долей
- Общий рынок: компании одного сегмента делят клиентов
- Дашборд: лига, гонка оценок, P&L, оргструктура, Slack компании, хроника, шоки рынка
- Повторы протоколов совета, питч-дек, некролог или история успеха (PNG), видео сезона (WebM)
- Режим сезона: несколько гонок по сидам и сценариям, таблица очков
- Защита: изоляция промптов, лимиты токенов, rate limit, ключи не попадают в логи и записи

## Команды

```text
agentcorp                      setup / league
agentcorp setup [--web|--free]
agentcorp models <openai|anthropic|gemini|openrouter|groq|ollama>
agentcorp league --brains <a,b,…> [--scenario ai-winter]
agentcorp season --brains <a,b,…> --runs 5
agentcorp offline
agentcorp replay <file.json>  ·  agentcorp export <file.json>  ·  agentcorp pitch <file.json>
```

## Ключи и безопасность

Ключи хранятся только в `.agentcorp/config.json` на вашем компьютере. Папка исключена из git, а ключи вырезаются из логов, ошибок и записей. Сервер дашборда слушает только 127.0.0.1.
